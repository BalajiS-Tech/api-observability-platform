# 🚀 API Observability Platform

A production-style API monitoring and observability system that tracks uptime, response time, and error analytics with a real-time dashboard.

---

## 📌 Features

- API health monitoring
- Cron-based automated checks
- Response time tracking
- Error logging & categorization
- Uptime percentage calculation
- Interactive dashboard with charts
- Status indicator (UP/DOWN)
- Email alert support

---

## 🛠 Tech Stack

Backend:
- Node.js
- Express.js
- MongoDB
- node-cron
- Axios

Frontend:
- React.js
- Chart.js
- Axios

Tools:
- Git
- Postman

---

## 🏗 Architecture

React Dashboard → Express API → MongoDB  
Cron Jobs → Automated API Monitoring → Logs → Analytics Dashboard

---

## 📊 Dashboard Capabilities

- View monitored APIs
- Track response time trends
- Analyze error patterns
- Monitor uptime percentage
- View API status in real time
